# Personal Portfolio / Journal Starter

Minimal geometric portfolio system focused on process, reflection, and growth.

## Structure

- `index.html`: one-page foundation with required sections.
- `styles.css`: geometric visual language, motion rules, accessibility baseline.
- `docs/narrative-thesis.md`: voice and story arc.
- `docs/visual-grammar.md`: primitive meanings, constraints, composition rules.
- `docs/information-architecture.md`: page model and content schema.
- `docs/quality-gates.md`: release quality checks.
- `content/projects/project-template.md`: project writing template.
- `content/journal/journal-template.md`: journal writing template.

## Launch target (v1)

- 3 strong project entries.
- 5 journal entries.
- All quality gates passed.

## Two-week cadence

- Publish one reflection entry every two weeks.
- Ship one micro visual refinement each cycle.
- Remove one decorative but meaningless element each cycle.

## Weekly checklist

- Write one honest paragraph about current creative struggle.
- Replace one generic sentence with concrete evidence.
- Capture one screenshot for style consistency log.
- Note one unresolved question for next iteration.
