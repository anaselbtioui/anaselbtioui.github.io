# Information Architecture

## Primary pages
- Home
- Work
- About
- Journal
- Now
- Contact

## Navigation principle
Reduce choices, increase depth. Keep top nav fixed to six entries only.

## Page purpose
- Home: thesis + signature visual + path into work/journal.
- Work: project archive with process-first cards.
- About: personal context without vanity framing.
- Journal: timeline of experiments and self-discovery writing.
- Now: current priorities and active constraints.
- Contact: simple collaboration channel.

## Project card schema
Each card must surface:
- problem;
- artistic intent;
- process;
- outcome;
- reflection.

## Journal taxonomy
- process-notes
- design-philosophy
- self-discovery-log
