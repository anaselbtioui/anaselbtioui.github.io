# Visual Grammar

## Geometric primitives

- Circle: memory and continuity.
- Line: tension and direction.

Only these primitives may appear in interface motifs, separators, icons, and transitions.

## Signature motion

Slow orbital drift tied to scroll progress.

- Reading mode speed: 180ms-240ms, subtle and nearly static.
- Transition mode speed: 420ms-560ms, used for section changes.

Motion explains structure and state, never decoration.

## Visual constraints

- No stock photography.
- No gradients.
- No glassmorphism effects.
- Max two typefaces.
- Max three semantic colors: neutral base, accent, emotional state.

## Grid + composition

- Base grid: 8px spacing scale.
- Main content: 12-column layout on desktop.
- Asymmetry allowed only in hero composition.
- All other sections must snap back to stable rhythm.

## Style consistency checklist

- Every section includes circle or line motif linked to meaning.
- Accent color appears only on interaction points and key statements.
- Negative space carries hierarchy before font weight does.
- Any new visual element must reference circle or line logic.
